# 站点配置运行时实施记录

本轮执行用户批准的「配置 + 通用运行时 + 可信适配器」方案。仅在本地实施，不提交或推送 GitHub，不编译 FastlaneTool。

1. schemaVersion 2：注册表、显示信息、身份断言、正文/分享模板、数组附件、独立下载域、变换参数、可信动作、可选默认标签；兼容 v1。
2. 统一网络匹配和运行生命周期：动态启停/重载、过期响应隔离、主动 GET、确定性站点选择。
3. 迁移内置配置：BugDone 旧标记兼容层、友盟日志关联适配器、GitHub 身份规则；显示文案由配置提供。
4. 配置编辑/试运行/回滚及默认标签交互；更新使用文档。
5. 回归测试与分支审查；不创建实际业务任务。

裁决：保留 BugDone 旧查重缓存和标记作为兼容适配器；不能因升级配置造成重复任务。友盟关联与 BugDone 状态写回仅允许可信适配器，不接受任意脚本/任意 POST。
裁决：defaultLabel 缺省或 mode=inherit 继承全局，mode=none 明确不带，mode=fixed 使用工作区内标签 UUID（绑定 API 根地址和工作区）；不自动跨工作区套用。

## 运行边界

普通 JSON 列表/详情站点可通过配置扩展。友盟日志关联和 BugDone 读状态→写状态→确认流程保留在可信适配器；新协议或新写回动作需要脚本升级。配置中的 postActions 不能执行任意 JavaScript 或任意 POST。

Mac 原生共享存储、原生网络桥真实上传、大附件分块和智能体附件可读性仍由用户编译运行后按 local-acceptance.md 联调，是发布门槛；本轮浏览器合成验证不替代这些检查。
