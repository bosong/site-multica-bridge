# 捕获设置落地计划

## 范围
- 设置页新增独立“捕获设置”卡片；原“站点捕获配置”Tab 更名“站点配置”。
- 捕获总开关暂停自动接口监听/主动页面请求，保留当前记录、任务及手动填写；站点启停不受总开关影响。
- 动态站点开关和内置站点卡片的蓝色胶囊开关共用 profile.enabled，通过现有持久化和运行时刷新应用。
- 图片默认压缩/原图、日志默认精简/完整版、默认关联捕获附件三个偏好自动保存；仅影响后续记录/新草稿。
- 自动关联关闭后可在任务页预览并手动添加来源附件；已有附件及用户选择保持不变。
- 恢复偏好恢复图片、日志、自动关联默认值，保留总开关和各站点启停、连接信息、用户数据。

## 实施顺序与验证
1. 先补偏好归一化、恢复范围、附件选择保留等回归测试。
2. 加入配置字段、暂停生命周期、每记录默认版本选择。
3. 添加设置卡片、动态开关、内置卡片开关与 Tab 名称，复用同一 profile 持久化。
4. 按新草稿选择自动附件，提供来源附件手动加入/移除入口。
5. npm 检查与全量测试；Ego Lite 用合成响应验证暂停/恢复、双向开关联动、附件默认与手动添加、偏好恢复。
6. 更新版本、文档和更新记录后提交推送。

## 验收结果
- v2.4.0：141 项测试通过，语法检查和差异检查通过。
- Ego Lite：设置四类独立卡片、蓝色胶囊开关、版本分段按钮、内置卡片/设置双向同步、暂停/恢复、原图手动添加及移除后重添、恢复默认保留暂停及站点关闭状态、未保存 JSON 保护均已验证。
- 验证只使用合成响应与模拟网络，不创建真实 Multica 任务。
