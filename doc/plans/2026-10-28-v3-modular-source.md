## 需求与范围

- 用户仍安装一个 `bugdone-multica.user.js`；文件名、updateURL、downloadURL、namespace 和权限声明保持兼容，仅版本改为 3.0.0。
- 开发只修改 `src/` 和构建脚本，禁止手工修改最终生成文件。
- 不新增业务功能，不改接口参数、查重标记、站点 ID、存储命名空间及持久化键，不迁移或清除用户数据。
- 保留油猴、无 GM API 的网页回退、FastlaneTool 原生网络/存储桥及桌面程序入口。
- 保留全部站点配置、捕获设置、任务创建、来源附件、状态查询和当前 UI。
- 本次不引入 UI 框架、不重写业务状态为新的状态库；启动控制器保留现有会话生命周期。优先拆出独立逻辑、存储/网络/附件服务、UI 模板和挂载逻辑，避免同时改变交互。
- 产品代码不使用 eval/new Function 动态加载模块，不从 CDN 或运行时远程加载依赖。
- 构建保留可读代码。开发可生成 source map，正式脚本不携带本机路径或测试数据。

## 文件与职责

- `src/index.js`：浏览器启动与协议守卫。
- `src/app.js`：会话状态及生命周期协调；保留原有初始化顺序，委托模块执行。
- `src/core/index.js`：核心模块公共导出入口，供应用与测试复用。
- `src/config/`：默认值、版本及快捷键/捕获偏好。
- `src/sites/`：内置 JSON 配置与 BugDone、友盟专用处理。
- `src/capture/`：规则匹配、校验、归一化、草稿、接口和路由监听。
- `src/multica/`：连接校验、任务/查重/状态与网络请求。
- `src/history/`：来源链接和站点筛选逻辑。
- `src/platform/`：存储和页面世界注入代码。
- `src/attachments/`：下载、压缩与上传服务。
- `src/ui/`：主面板挂载、HTML 模板、CSS 与入口几何计算。
- `src/userscript.meta.txt`：油猴元数据模板。
- `scripts/build.mjs`：构建单文件、隔离页面世界代码、watch 与构建校验。
- `test/helpers/`：模块加载和旧运行时片段测试的适配。旧测试适配读取当前模块源码，不保留冻结的旧产品源码；新的行为测试直接覆盖模块/构建结果。
- `.generated/`：临时版本、测试 bundle 和开发 map，忽略提交。
- `bugdone-multica.user.js`：确定性生成的可安装产物，随分支提交。

## 审查重点

1. 依赖循环或初始化顺序变化：无配置、缺少可选字段、无 GM API 时仍能启动。
2. 注入到页面世界的代码不能依赖构建器改名后的外部函数：注入代码单独打包并验证。
3. 存储键、查重格式及权限声明不得意外改变；已有配置与处理历史保留。
4. UI 挂载模块仍需读写同一会话状态：暂停、站点切换、附件选择和未保存 JSON 不被快照覆盖。
5. 构建不能读取令牌/本机配置、打包测试私密样本或依赖外网；两次 build 的正式产物应一致。
