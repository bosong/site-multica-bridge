## Mac App WebView

1. 在油猴编辑器中**全选并替换**旧脚本源码为本地 `bugdone-multica.user.js`，不要把新版粘贴到旧版后面；保存后刷新目标页。确认脚本已启用，BugDone、友盟和一个未配置的 HTTPS 网页均出现入口。切换这三个站点后，API 地址、令牌、工作区和默认选项仍能恢复。
2. 在未配置网页选中可见文字，点击「从当前页面选取」；应只生成可编辑草稿。选中工作台文字或包含表单/显式隐藏节点的区域应被拒绝。刷新页面、切换 SPA 路由后，未配置站点不应自动捕获网络响应。
3. 在 BugDone 打开详情，核对标题、描述、截图与来源链接。手动编辑第一栏内容后等待详情刷新，编辑应保留；点击「恢复」才重新生成。进入第二栏后，删除某个截图，提交时不应上传被删项。
4. 在友盟打开崩溃详情与错误明细，核对列表、详情、行为日志和堆栈对应同一个应用与错误 ID；未打开的明细数量应被提示。长堆栈应出现在可移除附件列表。
5. 用一个小于 1 MiB 的**合成**文本附件创建测试任务，确认 Multica 任务能看到 `attachment_ids` 对应的文件，智能体能读取内容。再用 1–20 MiB 合成文件验证新原生桥的分块上传；旧版 App 应明确提示更新。再打开同一来源并提交，应复用已有任务且不重新上传。
6. 在「站点捕获配置」Tab 查看内置 BugDone、友盟和 GitHub Issues JSON，确认三个域名和友盟开关状态正确。点击「使用合成模板新建」，按字段说明导入合成 profile；初次保存应停用，启用后扩大监听接口再保存，应再次停用并列出新增范围。导出的 JSON 应只含规则，不含 API Token、Cookie 或捕获正文。
7. 在合成 profile 中配置响应内文本和独立 CDN HTTPS 图片字段，确认捕获后进入任务附件列表且可移除；超出 `maxChars` 或图片地址越域时应提示未包含且不上传。需源站 Cookie 才能访问的图片应明确失败并停止创建。
