# 入口显示范围与轻量站点配置升级计划

用户已批准“配置页面自动显示，其他页面快捷键临时打开”的方案并要求执行。

## 目标与边界

- 默认 entryVisibility=configured；可选 all（所有 HTTPS 页面）、shortcut（仅主动打开）。沿用 HTTPS @match，不要求用户改脚本头。
- captureMode 缺省 api，兼容现有三份接口配置；新增 text、blank，两者无需 captures/record/dedup，不安装网络捕获，不接受自动附件或源站动作。
- text 模板只替换 pageTitle/pageUrl/selectedText；选择文字仍由用户点击，沿用选区可见性校验。blank 默认空标题/正文，允许直接填写。
- 轻量配置 pages 支持 kind=manual；其 /** 仅表示该 origin 的所有页面，不改变原有接口路径匹配语义。
- 未匹配页面不自动挂载 UI、不自动连接 API；快捷键或油猴菜单可即时打开，再按需连接。已打开任务和手动编辑不因入口隐藏而丢弃。
- 保留现有来源查重、附件、存储与位置校正；手动模板草稿仍是 manual 身份，不伪称业务来源查重。
