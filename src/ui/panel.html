SOURCE CONFIGURATION

站点配置

用于定义目标网站、适用页面和信息捕获规则，将捕获结果整理为 AI 任务的标题、内容和附件。内置配置可直接使用或调整；新增网站请先选择“新建配置”，再使用模板。

内置站点配置

导入声明式 JSON 配置，可为 HTTPS 网站指定列表页、详情页、接口和字段映射。配置不会执行网页脚本；保存后当前页面立即应用；其他已打开页面需刷新。

内置配置也可调整；删除内置覆盖会恢复默认。来源身份与查重键保持稳定，自定义配置保存后手动启用。

进入任务创建页时应用；用户最后的选择优先。指定标签不会跨工作区使用。修改后点击校验并保存。

用合成响应试运行字段映射

配置字段说明与填写规则
captureMode
api（缺省）接口捕获；text 只在主动捕获时把 pageTitle/pageUrl/selectedText 填入 draft 模板；blank 空白填写。text/blank 可省略 captures、record、dedup，不能声明自动附件或源站动作。
schemaVersion
配置格式版本；支持 1 和 2，新配置使用 2。
id
站点配置唯一标识，使用小写字母、数字和连字符；不能与内置配置重复。
version
此配置的修订号，修改映射时建议递增。
enabled
是否自动捕获；新导入默认停用，核对后在此页启用。
allowedOrigins
允许读取的 HTTPS 站点根地址；不是页面路径，也不包含请求密钥。
pages
浏览器地址规则：kind 为 list 或 detail，path 支持单段 :参数 与 *。页面地址不等于接口地址。
captures
接口规则：id、GET/POST method、同站点 origin、path（可含 :参数）、maxResponseBytes；requestOnPage 可在当前匹配页面主动 GET JSON，可选 requestKeys 用于核对请求身份。
success
可选接口响应成功条件：有限的 JSON path 与 equals 值；若响应没有成功标志可省略。
variants
从响应中提取列表或详情：kind、JSON path、array/object type；列表包装项可用 itemPath 指向实际记录。
record
记录字段路径：scopeId、recordId、title 必填；number、descriptionHtml、descriptionText、sourceUrl 可选。路径支持 $.field.subfield，或按顺序取非空值的路径数组。
draft
任务标题模板 titleTemplate、可选正文模板 descriptionTemplate（支持 description/sourceUrl/shareUrl）；可插入 {{siteId}}、{{scopeId}}、{{recordId}}、{{number}}、{{title}}。
defaultLabel
mode: inherit 继承全局、none 不带标签、fixed 指定标签；fixed 必须同时配置 id、api、workspace。用户在任务创建页可覆盖。
identity
scopeTemplate 校验页面与记录范围，recordParam 校验详情编号，recordFormat 限制编号格式，sourceTemplate 核对规范来源链接。
metadata / presentation
name 显示来源名称；recordLabel 记录选择标题；hideSelectors / drawerSelectors 为简单 ID 或 class 选择器；drawerPaddingSelectors 在抽屉期间保持目标左内边距的正常值，关闭后恢复，用于兼容滚动条补偿。旧内置覆盖会继承此项默认值，显式 [] 可关闭。
links / processors
shareTemplate 生成只读分享链接；stack 中的 maxStacks、maxLines、maxChars 控制精简堆栈。
dedup
来源键模板 keyTemplate，必须包含 {{scopeId}} 和 {{recordId}}，用于跨浏览器查重。
attachments
最多 8 条：kind: text 读取响应文本，需 maxChars（最多 200000）；kind: image-url 读取配置允许的 HTTPS 图片地址。两者均需 id、path、filenameTemplate；items 配置数组内 url/name/filter，allowedOrigins 单独限定下载域，transform 配置图片压缩；提交前可移除。
postActions
可信动作列表。BugDone 支持 bugdone.start-processing，可用 enabled 关闭；仅新建成功执行，复用任务不写回。禁止任意脚本或 POST。
